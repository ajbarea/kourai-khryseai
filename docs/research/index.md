## [Kourai Khryseai: Transparent Human-on-the-Loop Multi-Agent Software Development](ne-agents-day-2026/index.md)

<a href="ne-agents-day-2026/index.md">

       alt="Kourai Khryseai conference poster preview"
       class="research-poster">

**Poster + extended abstract** · North-East AI Agents Day 2026, Jane Street NYC · May 8, 2026

Multi-agent coding systems that treat collaboration as a *supervised* problem — an orchestrator routes to specialist agents for planning, coding, testing, style review, and commit synthesis while streaming intermediate status and pausing on ambiguity. A shared A2A + MCP + OpenTelemetry backend drives three interfaces: terminal REPL, pygame chat with TTS voices, and an illustrated Ren'Py visual novel.
